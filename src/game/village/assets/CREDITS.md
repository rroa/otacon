# Village assets — provenance and licence

Everything here is **CC0 / public domain**, deliberately. Canabalt's assets are
why this repository is private; the isometric work uses only assets that could
be published, so this part is not what keeps it closed.

## iso.png / iso.atlas — Kenney Isometric Miniature Prototype

* **Source:** <https://kenney.nl/assets/isometric-miniature-prototype>
* **Licence:** CC0 1.0 — free for personal, educational and commercial use.
  Crediting Kenney is optional; we do it anyway.
* **Original:** 240 sprites, each on a 256×512 canvas, 8-bit palette PNG.

### What was done to it

Generated by `tools/isopack` (see that file for the reasoning):

```
cmake --build build --target isopack -j8
./build/bin/isopack <kenney>/Isometric src/game/village/assets/iso.png \
                    src/game/village/assets/iso.atlas 4
```

Downsampled 4:1, trimmed to each sprite's opaque bounds, packed into one atlas.
**120 MB of raw texture became 2.1 MB** — the pack as shipped is mostly empty
canvas, and loading it naively is not something you can do.

### The geometry, measured rather than assumed

| | |
|---|---|
| Diamond | **2:1** — 256×128 at full size, 64×32 after the 4:1 downsample |
| Canvas | 256×512 → 64×128 |
| Anchor | **shared** — every sprite bottoms out at the same canvas row |

That shared anchor is why the manifest records a trim offset per region: draw a
sprite at `position + offset` and it lands exactly where the artist put it, so
sprites compose without a per-sprite offset table.

## Candidates for the village demo (downloaded, not yet processed)

* **Feudal Wars** — <https://opengameart.org/users/feudalwars>. Public domain,
  originally made for a browser RTS. Barracks, blacksmith, stable, archery
  range, castle, guard towers, houses.
  **Caveat:** every building is its own size (305×222, 315×250, 500×422…) with
  **no shared canvas**, so each needs its own anchor determined before it can
  be placed on the grid. That is work Kenney's pack does not require.
* **Isometric Medieval Pack** (itch.io, 269 tiles, CC0) — terrain, roads,
  rivers, vegetation *and* buildings from one artist, which is the safer single
  choice for a coherent village scene.

Mixing packs risks mismatched palette, light angle and tile footprint. Check
those before committing to a combination.
